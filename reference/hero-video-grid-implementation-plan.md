# Hero Video Grid 実装計画書

## 概要

既存のトップページ Hero セクションへ、3カラムの縦動画背景を実装する。

現在の Hero
レイアウト・余白・コピー・CTA・スクロールアニメーション等は変更しない。

背景レイヤーのみを動画グリッドへ置き換える。

------------------------------------------------------------------------

## 実装方針

既存 Hero の DOM 構造・CSS は極力変更しない。

以下の構成を追加する。

``` text
Hero
├── Hero Background
│   └── Video Grid（追加）
├── Overlay（既存）
│   ├── Heading
│   ├── Copy
│   └── CTA
└── Scroll Indicator
```

背景画像を3カラム動画へ置き換え、オーバーレイは既存実装をそのまま利用する。

------------------------------------------------------------------------

## デザイン

背景は3カラム構成とする。

``` text
┌─────────────────────────────┐
│      │      │      │
│      │      │      │
│      │      │      │
│      │      │      │
└─────────────────────────────┘
```

各動画は `object-fit: cover;`
を使用し、既存のグラデーション・タイトル・CTA は変更しない。

------------------------------------------------------------------------

## レスポンシブ

既存 Hero のブレークポイントに従う。

### Desktop

-   3カラム

### Tablet

-   2カラム

### Mobile

-   1カラム

------------------------------------------------------------------------

## HTML

既存 Hero 内へ追加する。

``` html
<div class="hero-video-grid">
  <video class="hero-video"></video>
  <video class="hero-video"></video>
  <video class="hero-video"></video>
</div>
```

既存 HTML の変更は最小限とする。

------------------------------------------------------------------------

## CSS

新規 `hero-video.css` を作成する。

``` css
.hero-video-grid{
    position:absolute;
    inset:0;
    display:grid;
    overflow:hidden;
}

.hero-video{
    width:100%;
    height:100%;
    object-fit:cover;
}
```

既存 Hero CSS の変更は最小限とする。

------------------------------------------------------------------------

## JavaScript

新規 `hero-video.js` を作成し、Hero動画の制御のみを担当させる。

### 動画リスト

`heroVideos.js`

``` js
export default [
  "hero/hero_a225005.mp4",
  "hero/hero_a225007.mp4",
  "hero/hero_a225010.mp4"
];
```

ディレクトリ走査は行わず、配列で管理する。

------------------------------------------------------------------------

## 初期表示

-   ランダムに3本選択
-   重複禁止
-   `muted`
-   `autoplay`
-   `playsinline`

------------------------------------------------------------------------

## 切り替え

動画終了時

1.  `ended`
2.  未使用動画をランダム選択
3.  フェードアウト
4.  `src`変更
5.  再生
6.  フェードイン

CSS Transition を利用する。

------------------------------------------------------------------------

## パフォーマンス

-   `preload="metadata"`
-   音声なし
-   Hero専用に圧縮した動画を使用
-   DOM上の `<video>` は最大3つのみ

------------------------------------------------------------------------

## IntersectionObserver

Hero が画面外では `pause()`、画面内で `play()` を実行する。

------------------------------------------------------------------------

## Reduced Motion

`prefers-reduced-motion: reduce` の場合は動画を停止し、既存 Hero
背景画像を表示する。

------------------------------------------------------------------------

## 保守性

動画追加時は

1.  `public/hero/` に動画を追加
2.  `heroVideos.js` に1行追加

HTML・CSS・JavaScript の修正は不要とする。

------------------------------------------------------------------------

## Cursor 実装時の注意事項

-   既存 Hero の高さ・レイアウトは変更しない
-   Overlay・CTA・スクロールインジケータへ影響を与えない
-   背景レイヤーのみ動画化する
-   JavaScript は Hero 動画専用モジュールとして実装する
-   `z-index` のみでレイヤー制御を行う
-   既存アニメーションとの競合を避ける
