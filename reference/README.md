# メディア表現学科 バーナム体験診断（プロトタイプ）

静的 HTML＋`js/app.js` で動く授業デモ用の Web 診断です。詳細な仕様は [SPEC.md](docs/SPEC.md) を参照してください。

## 診断結果に出る「タイプ表示」（4文字コード＋二つ名）

結果画面の上部に表示される **4文字の英字コード** と **括弧内の二つ名**（「〇〇する者」形式）は、コード上では `TYPE_ARCHETYPES` と呼ばれています。特定の職業名ではなく、**場面で発揮されそうな役割のイメージ**を短くラベル化したものです（実在の性格診断タイプではありません）。

本文の段落は、この二つ名ごとに固有の文章があるのではなく、下記の **バーナム文プール**（6カテゴリから各1文）を組み合わせて生成されます。二つ名は主に **見た目の体裁**（MBTI 風の「型コード」感）としてランダムに割り当てられます。

## 結果本文（バーナム文）の構造

本文は次の **6カテゴリ** からそれぞれ1文ずつ選ばれ、3段落に埋め込まれます（`BARNUM` オブジェクト）。

| カテゴリ | 役割（ざっくり） |
|----------|------------------|
| positive | 肯定的・強みめいた記述 |
| duality | 両義性・揺れ（明るい／暗い両面） |
| social | 他者から見た印象 |
| internal | 内面の葛藤・迷い |
| desire | 願い・価値観 |
| future | これからの可能性 |

カテゴリ名と設問バンクの `category`（`questions.json`）は対応していますが、**表示される二つ名と本文の文の組は独立**（ランダムまたは URL パラメータで固定）です。

## 開発メモ

- 設問の更新: `questions.json` を編集後、`node build-questions.mjs` で `js/questions_embed.js` を再生成（[SPEC.md](docs/SPEC.md) 参照）。
- タイプの追加・変更: `js/app.js` の `TYPE_ARCHETYPES` を編集。
