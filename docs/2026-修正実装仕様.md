## 第2条（不具合修正：最優先）

### 2-1. 成果セクションの二重レンダリング

**症状**：TOPページ `#outcomes` 内で、3テーマ分のプレースホルダーカードが同一内容のまま2回連続で描画されている。

**原因（特定済み）**：`src/components/OutcomeSection.astro` の overview プレースホルダーが `Array.from({ length: 6 })` で6枚生成しており、3テーマ×2周になっている。

```astro
// 現行（問題箇所）
Array.from({ length: 6 }, (_, i) => {
  const t = (['takao', 'mizuno', 'yao'] as const)[i % 3];
```

**対応**：3枚のみ描画するよう修正する。

```astro
// 修正後
(['takawo', 'mizuno', 'yao'] as const).map((t) => ( ... ))
```

## 第5条（理論的背景の追記）

各セットページに1〜2文で挿入。「授業の流れ」の直後、「学生成果物」の前。見出しは `参考` を採用（サイトトーンに合わせて `理論的背景` も可）。

**高尾（takawo）**
> 本セットは、Sanders & Stappersによるデザインリサーチの分類のうち「Research through Design（実践を通じた研究）」に位置づけられる。4回の構成は、英国デザイン協議会が提唱する「ダブルダイアモンド」モデル（調査→定義→開発→提供）に沿っている。

**水野（mizuno）**
> 「日記を書くのは誰か」という問いは、山本浩貴（いぬのせなか座）が『生のアトリエ』で論じた、書くことが自分自身に考えさせる装置になるという視点を出発点にしている。

**八尾（yao）**
> 「何を、どこまで、誰のために残すのか」という問いは、東京藝術大学「日比野克彦を保存する」プロジェクトなど、近年のアートアーカイブ実践に共通する論点である。山口勝弘をはじめ、作家自身がアーカイブ制作を作品活動の一部として扱ってきた系譜にも接続する。

**実装案**：`src/data/site.ts` の `SET_META` に `reference?: string` を追加し、`ReferenceSection.astro`（新規）で表示。
